# Molt 1.2.0rc10

Released 2026-11-27. Prerelease for single-user Linux x86_64.

This release ships native packages for Debian/Ubuntu, Fedora/RHEL and Arch
Linux. It does not attach a portable tar.gz bundle; the source tree and CI can
still build one with `packaging/release/build-linux-x86_64.sh`.

## Assets

- `molt_*.deb` — Debian/Ubuntu package
- `molt-*.rpm` — Fedora/RHEL package
- `molt-1.2.0rc10+git3e7d01b-1-x86_64.pkg.tar.zst` — Arch Linux package
- `molt-debug-*.pkg.tar.zst` — Arch debug package
- `SHA256SUMS` — checksums for the packages

The packages are unsigned. Download the package for your distribution and
`SHA256SUMS`, then verify and install:

```bash
sha256sum --check --ignore-missing SHA256SUMS

# Arch Linux
sudo pacman -U ./molt-1.2.0rc10+git3e7d01b-1-x86_64.pkg.tar.zst
# Debian / Ubuntu
sudo apt install ./molt_*.deb
# Fedora / RHEL
sudo dnf install ./molt-*.rpm
```

The release declares glibc 2.43+ and Python 3.11+. These are release
declarations and packaging-metadata requirements (`packaging/native/nfpm.yaml`,
`PKGBUILD`), not a re-test performed by this release-notes update.

## What is included

The packages install a matched CLI (`molt`), TUI (`molt-tui`) and kernel
(`molt-kernel`) under `/usr/bin` and `/usr/lib/molt`, plus the user
`molt-kernel.service` unit under `/usr/lib/systemd/user`. Installation does not
enable or start the service. `molt tui --mock` runs Chat in offline mock mode;
Settings, Diff and Approval still use mock data in this prerelease.
