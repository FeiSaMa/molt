# Molt 1.2.0rc9

The first GitHub pre-release bundles the Python CLI, Rust kernel and TUI for Linux x86_64. It includes project workspace versioning, atomic saves, snapshot pinning, rollback, local event audit and TUI session recovery. In the Versions panel, press `v` after a successful save to inspect the generation, snapshot, event and original request ID.

## Download and try

Download the Linux archive and its matching checksum from the [GitHub release](https://github.com/FeiSaMa/molt/releases/tag/v1.2.0rc9). Keep them in the same directory.

```bash
sha256sum -c molt-1.2.0rc9-linux-x86_64.tar.gz.sha256
tar -xzf molt-1.2.0rc9-linux-x86_64.tar.gz
cd molt-1.2.0rc9-linux-x86_64
./bin/molt-tui --mock --selftest --width 80 --height 24
```

Start with the offline sandbox walkthrough in the bundle at `share/molt/README.md`. It includes the prerequisites for user installation and the steps to run a foreground kernel with disposable state. [Source build and project walkthrough](../../README.md) · [中文版](../../README.zh-CN.md)

## Release evidence

- Archive SHA-256: `90b9eb222550792afbdbea02b6f38eb6706f045336caea87c2868de496d9c6a7`.
- Build and package tests ran in an isolated Ubuntu 24.04.5 x86_64 userland with glibc 2.39 on a Linux host. The cold locked build downloaded and compiled 99 locked crates. The exact archive passed rc8 upgrade, reinstall, failure preservation and eight outside-checkout package regressions.
- A real 80×24 terminal with synthetic state exercised two save receipts, stale-generation retry with draft retention, event audit and pinned Tree reads after rollback. Recovery tests covered the original request ID after interruption and response loss. One fault-test environment used a loader shim.
- Kernel ELF version requirements reach glibc 2.34. The TUI has weak glibc 2.39 references. Ubuntu 24.04.5 is the tested userland. Older glibc userlands, other distributions and architectures, persistent user services, independent contributor trials and production deployments are outside this release's acceptance scope. Chat used mock data in these package tests. Settings, Diff and Approval are prototype panels.

For unexpected install, TUI or recovery behavior, include your distro, glibc version, archive SHA-256, terminal size, command and sanitized output.
