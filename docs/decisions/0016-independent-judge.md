# ADR 0016：独立 Judge 与执行观察边界

- 状态：设计基线已接受；实现未授权
- 日期：2026-11-16
- 关联：ADR 0011、0015

## 背景

ADR-0015 将独立 judge 与内核观察执行留作 M4，但未定义其接口、信任边界或验收。M4 应提高执行事件与判分证据的独立性，不能改变 v1 verifier、scenario、holdout 或 gate 语义，也不能把本地存储完整性误称为执行真实性。

## 决定与范围

M4 定义为一个独立于被测 agent/执行进程的 judge 进程，以及由该进程产生的、可关联到 kernel generation 的观察记录。Judge 只接收执行身份、声明的观察策略和有界事件流；它不得接受被测进程给出的最终判分作为事实，不得改写 kernel state、证据对象或业务结果，也不得联网或运行 agent。Judge 的结论是带来源与限制的观察报告，现行 verifier 仍是语义判分权威；在另行 ADR 前，judge 报告不能单独触发 adopt、gate 通过或 holdout 解封。

M4 不包含通用沙箱、不声称防御同 UID/root、内核、宿主机或 judge 二进制被攻陷的攻击者，不保证外部进程观察到的事件完整，不证明代码确实按声明执行，也不改变 v2 本地哈希链的外部检查点限制。它不自动获得网络隔离、系统调用拦截或跨主机信任能力。

## 接口合同（实现前冻结）

Judge 采用一次执行一个请求的本机 IPC；传输与认证方案须在实现设计中选定并威胁审查。请求为版本化 canonical JSON，至少包含：

- `protocol`、唯一 `request_id`、`run_id`、`state_id`、预期 `generation`/manifest 摘要；
- 被测命令的可审计标识、工作目录身份、开始/截止时间和资源上限；不得把任意环境变量秘密复制进请求或报告；
- 明确的观察策略版本和事件类型允许列表；观察范围须为只读，策略外信息不应被采集；
- kernel 侧可验证的输入对象引用，而非由 judge 自行解析业务结果或覆写存储。

响应为不可变观察报告，至少包含：协议与 judge 版本、请求/运行/状态关联 ID、观测起止时间、策略摘要、按序事件摘要及丢失/截断标记、退出状态或明确的 unavailable/timeout/unknown 结果、报告内容摘要。响应须由独立 judge 身份认证；签名密钥与被测进程可写 state 分离。报告以普通不可变对象提交到指定 generation，失败时不得伪装成成功观察；重试使用同一 request ID 并返回既有报告或明确冲突。

事件模型、传输认证、签名密钥持有方式和资源/隐私上限，须在 M4 实现 ADR 中细化后方可编码；本文件仅冻结最低语义和权限边界。

## 威胁模型

受保护目标：让 verifier/审阅者区分 judge 实际观察到的事件、被测进程自报的事件、观察缺口及最终业务判分；防止被测进程直接伪造或修改已认证的 judge 报告。

假设 judge 可执行文件、其身份密钥及受信任宿主内核在执行期间未被攻击者控制；judge 与被测进程具有可区分的 OS 身份或等效强隔离，且 judge 输出密钥不能由被测进程读取。若部署不满足，报告必须标注为非独立观察，不得按 M4 证据接受。

不防御宿主机管理员/root、内核攻陷、judge 本身漏洞、物理/电源攻击、同一信任域同时控制 judge 与其密钥，或超出明示观察策略的隐蔽副作用。不得宣称 judge 是完整 sandbox、数学证明或 tamper-proof 可信执行环境。

## 验收标准

实现 PR 前须有可复现威胁审查、协议 schema/golden vectors 和失败语义。实现验收至少包括：

1. 独立身份与权限测试：被测进程无法连接冒充的 judge 身份、读取签名密钥、篡改 judge 输出或向 kernel 直接写报告；不满足隔离前提时 fail closed 或显式降级标记。
2. 协议测试：版本/字段拒绝、canonical bytes、重复 ID 同请求幂等、同 ID 异请求冲突、generation 绑定、超时/断线/重启后的 unknown 处理及认证失败拒绝。
3. 观察完整性测试：正常退出、非零退出、超时、judge 崩溃、事件缺失/重排/重复/截断、资源上限、策略外事件和被测进程伪造自报事件；报告须将观察缺口显式表达。
4. 存储与审计集成：报告摘要绑定到 kernel generation；篡改、错 state/run/generation、缺报告和非独立报告均由审计识别，不改变现有 verifier 结果或 gate 语义。
5. 零写入、secret scan、隐私最小化、Rust/Python 全量回归及文档化残余风险通过；失败不得静默降级为可信 judge 报告。

## 排期边界

本 ADR 只定义 M4 的设计与测试基线，不授权实现或发布，不把 M4 加入当前回归承诺。M5 没有已审阅范围或验收，本轮不定义、不排期；须由维护者另行提交目标与验收后决策。
