# 代码与文档风格

Python 源码支持 3.11 及以上版本。日常验收使用 3.12.13，格式与 lint 规则以 `pyproject.toml` 为准。公开函数和持久记录使用类型标注，路径操作使用 `pathlib.Path`。

v1 字段说明由 `molt schema docs` 生成。引用[协议参考](protocol.md)中的结构。需要改变已冻结的契约时，先提交设计决策。

Markdown 使用相对链接和带语言标签的代码块。可执行示例说明工作目录、必要依赖和环境变量；持久状态与测试输出指向独立目录。存储时间使用 UTC ISO 8601，文档使用本地时间时注明时区。

证据说明应区分合成对象、历史回放与实际执行。记录源码或安装包标识、环境和命令。校验日志链能验证记录的一致性，执行结果仍依赖各证据来源。
