# Security policy / 安全报告

Report a suspected vulnerability using GitHub's private vulnerability reporting form. Include the affected version or commit, the impact you observed, and the minimum information needed to investigate. Use synthetic or redacted data and omit credentials and user state. [Report a vulnerability](https://github.com/FeiSaMa/molt/security/advisories/new)

如发现安全漏洞，请通过 GitHub 私密漏洞报告提交。请附上受影响的版本或提交、观察到的影响和排查所需的最少信息。使用合成或脱敏数据，移除凭据与用户状态。[私密漏洞报告](https://github.com/FeiSaMa/molt/security/advisories/new)

Use the public issue tracker for ordinary bugs and feature requests. 普通缺陷和功能建议可提交到公开 Issues。[Issues](https://github.com/FeiSaMa/molt/issues)
