02

probe 评测准则：怎样才算真的学会？

  1. 不背答案同一道题给多个用例，规则要能解释这些用例，而不是记住单题答案。
  2. 换题再试换到没见过的 headroom 题，验证规则能否迁移，而不是只对原题有效。
  3. 检查副作用回测原有能力；变差就记录负迁移，同时记录成本，不能只挑成功案例。

所以我们展示的是：规则从哪来、迁移到哪题、通过率怎么变。

MOLT · 迭元 —— 自进化：让经验跨任务复用，并用独立题目验证。

03

模型不会因运转而自新，唯能易其元、写其身，方得进化。

自进化的门槛，不在模型强度，而在流程记忆 —— 跨轮经验能否被保留、调用并复用。

  1. 01 / 现状 每一次都从零开始

    用哪档思考、按什么顺序调工具，靠人拍。跑完就散，经验不进下一轮。

  2. 02 / 代价 掉进同一个坑

    一次失败的尝试只是失败。
    换个任务名，同一个错再犯一遍，成本照付。

  3. 03 / 我们要的 把尝试变成资产

    失败不是沉没成本，而是可溯源的研究证据。成功可复盘，失败可回退，负结果可复用为下一轮改进的边界。

落到工程上是四件小事：改得动、量得出、退得回、说得清。

本项目只动两个开关（思考档位 high → low、工具调用顺序），在 10 道题上给出一次可复算的对照 —— 不是通用结论。

04

ARCHITECTURE / EVOLUTION LOOP

两层回路：把一次执行，变成下一轮的资产

上层管上下文，底层管证据；每次采纳都要过 gate，每次回退都保留历史。

上层给上下文，底层给证据；采纳与回退都落到可追溯的 snapshot / evidence，不把“加载了技能”说成“能力已提升”。

术语速查

    
  

  
按演示里出现的顺序；每个词只答「是什么、别误解成什么」。

  

    
gate / 门禁
采纳前的自动判定链：上限、无效比例、预算、通过数、成本逐项检查，全过才保留新版本。别误解成人工评审。

    
probe / 探针
专门测「有没有学会」的小题组。不是产品功能，也不是通用能力评测。

    
headroom / 提升空间
基线完全不过、留给规则去学的题。别误解成性能余量，也不等于难度分级。

    
REPLAY / 回放
重放已保存的运行记录并重算指标，不产生新的模型调用。别误解成重新跑了一遍。

    
live / 现场
真实模型调用产生的记录。本页只有一条 live，其余是回放与桩数据。

    
fixture / 桩数据
不调用模型的合成输入，用来验证流程与判分器。别误解成真实运行结果。

    
留出集（holdout）
不参与调参的题，用来检查提升不是只对搜索集有效。别误解成又一组练习。

    
gate 级 / 扫描级
gate 级是逐题配对（单题成本）；扫描级是整批题的总成本与墙钟。别把两个口径的数字放在一起比。

    
负迁移
学了新规则后，原本能过的题反而变差；x8 就是回归检查题。别误解成随机波动。

    
gen2 / gen3 / gen4
规则记忆的第 2 / 3 / 4 代。代数大不等于更好，要看通过率与回归。

    
x5–x8
迁移题编号：x5 unique、x6 dedupe_merge、x7 dedupe_min；x8 是回归检查，不计入提升。别把 x8 的成绩算进迁移收益。

    
verified=false
该数字当前无法从导出数据完整复算。页面如实标注，不当作已验证结论。

    
adopt / reject
门禁结论：adopt 采纳这一代；reject 拒绝并保留上一代。别误解成灰度发布或上线开关。

    
C1b / matrix
探针实验的内部编号；matrix 是多种模型设置的前置测试，用来说明题目有提升空间。别误解成模型排名。

    
Skill
可复用的操作说明或技能包，目标是把策略带到不同任务。本页没有真实 Skill 收益证据，不能写成能力变好。

    
MCP
连接模型与外部工具或资源的协议层。本页没有 MCP 收益实验。

    
RAG
检索增强生成：先检索资料，再把相关内容交给模型。本页没有 RAG 收益证据。

    
rollback / 回退
把当前状态指回已保存的历史版本，并保留历史；不重跑题目。底层 demo-6 是历史回退记录；chat 另有需用户触发、受 CAS 约束的状态图回退。新任务完成后自动评估并晋级 / 回退的通用闭环尚未接入。

    
CAS
content-addressed storage：按内容哈希寻址，内容不变则地址不变。它是存储概念，不等于 gate 或回退。

    
n=1
现场闭环只有 1 条 live 候选记录。只能作现场证据，不能据此声称普遍收益。
